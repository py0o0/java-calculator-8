# 문자열 덧셈 계산기

## 개요
이 프로젝트는 문자열 형태로 입력된 숫자를 덧셈하는 **콘솔 기반 계산기**입니다.  

---

##  제약 조건

- 커스텀 구분자는 한 개만 허용한다.
- 커스텀 문자열은 빈 값을 허용하지 않는다. 다만 `\n`은 허용된다.

---

## 예외 사항

- 빈 문자열이 입력되는 경우
- 숫자가 아닌 값이 입력되는 경우
- 음수가 입력되는 경우
- 커스텀 구분자의 정의 형식 `//{문자}\n`을 따르지 않은 경우

---

## 후기

처음에는 단순한 알고리즘 문제로만 생각하고 main 메서드에 모든 기능을 작성했으나,  
곧 잘못된 접근임을 깨닫고 확장성과 유지보수성을 고려한 설계가 필요함을 깨달았습니다.

이후 구조를 리팩토링하여 입력 검증, 구분자 처리, 계산 로직을 책임 별로 분리하였고,  
향후 덧셈뿐만 아니라 뺄셈, 곱셈, 나눗셈의 계산까지 확장할 수 있는 구조로 설계하였습니다.

이번 과제를 통해 코드 설계와 책임 분리의 중요성을 다시 한번 느낄 수 있었습니다.
